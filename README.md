# MIID 4304 Taller 5 Empaquetamiento

Repositorio del Taller 5 de MIID 4304 Despliegue de Soluciones Analiticas.

## Estructura

- `package-src`: codigo, configuracion, dependencias y pruebas del paquete.
- `test`: script y datos para validar el paquete instalado.

## Version inicial

El repositorio inicia con la version 0.0.1 suministrada en los archivos del taller.
